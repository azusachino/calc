# 運転免許 本免学科 — 数値・規定の典拠（authority reference）

普通自動車 本免（学科試験）デッキの数字を**公式・準公式の典拠**で裏取りしたもの。
デッキを mint / 改訂するときはここを先に確認する。数値は法改正で動くため、各
`典拠` の URL を一次情報として再確認すること。最終照合: 2026-06-15。

裏取り対象デッキ:

- [`data/driving/numbers.json`](../../data/driving/numbers.json) — 速度・距離・時間・年齢
- [`data/driving/distance-inspection.json`](../../data/driving/distance-inspection.json) — 距離・駐停車・車検・停止距離

ローカル保存した一次資料は [`sources/`](./sources/) を参照（下表「典拠」欄に対応）。

## 1. 駐停車禁止場所（駐車も停車も禁止 / 道交法 §44）

| 場所 | 距離 | 典拠 |
| --- | --- | --- |
| 交差点と側端 | 5m 以内 | 警察庁・大阪府警 / `sources/osaka-tyusyaihan-rei.pdf` |
| 横断歩道・自転車横断帯の前後 | 5m 以内 | 警察庁「横断歩道は歩行者優先です」 |
| 道路の曲がり角 | 5m 以内 | 道交法 §44 |
| 踏切と前後 | 10m 以内 | 道交法 §44 |
| 安全地帯の左側と前後 | 10m 以内 | 道交法 §44 |
| バス・路面電車の停留所の標示柱の前後 | 10m 以内（**運行時間中に限る**） | 道交法 §44 |

> ひっかけ注意: バス停 10m は「運行時間中」限定。「いつでも」「30m」は誤り。
> 踏切は 5m ではなく **10m**。交差点は 3m ではなく **5m**。

## 2. 駐車禁止場所（停車は可・駐車のみ禁止 / 道交法 §45）

| 場所 | 距離 | 典拠 |
| --- | --- | --- |
| 駐車場・車庫など自動車用の出入口 | 3m 以内 | 警視庁除外標章例示 / `sources/keishicho-jogai.pdf` |
| 火災報知機 | 1m 以内 | 道交法 §45 |
| 消火栓・指定消防水利の標識・防火水槽の取入口 | 5m 以内 | 道交法 §45 |
| 道路工事区域の側端 | 5m 以内 | 道交法 §45 |
| 道路の右側に確保すべき余地 | 3.5m 以上（とれない場所は駐車不可） | 大阪府警 / `sources/osaka-tyusyaihan-rei.pdf` |

> ひっかけ注意: 火災報知機は **1m**（5m は消火栓と取り違え）。
> 車庫・駐車場出入口は **3m**（5m は誤り）。消火栓は **5m**（3m は誤り）。

## 3. 速度（道交法 §22, 政令 §11/§27）

| 区分 | 法定最高速度 |
| --- | --- |
| 一般道・普通自動車（指定なし） | 60 km/h |
| 一般道・原動機付自転車 | 30 km/h |
| 高速自動車国道 本線車道・普通乗用車 | 100 km/h（一部指定区間は 120 km/h） |
| 高速自動車国道 本線車道・最低速度 | 50 km/h |

## 4. 前照灯（道路運送車両の保安基準 §32）

| 種類 | 確認できる前方距離 | 典拠 |
| --- | --- | --- |
| 走行用前照灯（上向き・ハイビーム） | 約 100m | JAF faq158 / 警察庁 highbeam |

## 7. 追い越し禁止場所（道交法 §30）

| 場所 | 距離 |
| --- | --- |
| 交差点とその手前 | 30m 以内（優先道路通行中を除く） |
| 横断歩道・自転車横断帯とその手前 | 30m 以内 |

> 駐停車（5m）と追い越し（30m）で基準距離が違う点がひっかけになる。

## 7b. 環状交差点（ラウンドアバウト / 道交法 §35の2・§37の2）

警察庁・国交省の 4 ポイント: **右回り通行・環道優先・歩行者に注意・出るときに合図**。

| 項目 | 規定 |
| --- | --- |
| 通行方向 | 右回り（時計回り）の一方通行 |
| 優先 | 環道内を通行している車が優先（進入車は徐行して譲る） |
| 進入時の合図 | 不要 |
| 退出時の合図 | 出ようとする地点の直前で左の合図 |

> 平成 26 年（2014）9/1 施行。典拠: 警視庁「環状交差点の交通規制について」, JAF faq164, 国交省。
> ひっかけ注意: **反時計回り（左回り）は誤り**。日本は左側通行でも環状交差点は右回り。

## 7c. 追い越し禁止場所（道交法 §30）

| 場所 | 可否 |
| --- | --- |
| こう配の急な下り坂 | 追い越し禁止 |
| 坂の頂上付近 | 追い越し禁止 |
| こう配の急な**上り坂** | 禁止場所では**ない** |
| トンネル（車両通行帯なし） | 追い越し禁止 |
| トンネル（車両通行帯あり） | 禁止場所では**ない** |
| 交差点・踏切・横断歩道・自転車横断帯とその手前 30m 以内 | 追い越し禁止（交差点は優先道路通行中を除く） |

> ひっかけ注意: 急な**上り坂**は禁止場所でない（下り坂・頂上付近が禁止）。
> 交差点手前 30m は自分が**優先道路**を通行していれば追い越し可。横断歩道手前 30m は追い越し**と追い抜きの両方**禁止。

## 8. 車検（自動車検査証の有効期間 / 道路運送車両法 §61・施行規則 別表）

| 車種・用途 | 初回 | 2 回目以降 |
| --- | --- | --- |
| 自家用 普通乗用車・小型乗用車 | 3 年 | 2 年 |
| 自家用 軽乗用車 | 3 年 | 2 年 |
| 事業用 旅客自動車（バス・タクシー等） | 1 年 | 1 年 |
| 自動二輪（250cc 超） | 3 年 | 2 年 |

> ひっかけ注意: 事業用旅客は **1 年**（2 年は誤り）。自家用は普通・軽とも初回 3 年・以後 2 年で同じ。
> 「10 年超で毎年車検」は 1995 年に廃止済み（現存しない制度）。

## 9. 停止距離（交通教則）

- 停止距離 = 空走距離 + 制動距離。
- **空走距離は速度に比例**（速度 2 倍で約 2 倍）。
- **制動距離は速度の二乗に比例**（速度 2 倍で約 4 倍、3 倍で約 9 倍）。
- 車の重量が大きいほど制動距離は長くなる。

> ひっかけ注意: 「空走距離が速度 2 倍で 4 倍」は誤り（4 倍になるのは制動距離）。
