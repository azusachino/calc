## Lee215's Master Techniques

### 🌟 Key Insights from Lee215

Lee215 is renowned for **concise, elegant solutions** and creative problem transformations. Here are his signature techniques:

#### 1. **Sliding Window Template**
Lee215's unified template solves most substring problems:
```cpp
unordered_map<char, int> need, window;
int left = 0, right = 0, valid = 0;

while (right < s.length()) {
    char c = s[right];
    right++;
    // Update window

    while (/* window needs shrinking */) {
        char d = s[left];
        left++;
        // Update window
    }
}
```

#### 2. **Monotonic Stack/Deque Pattern**
- **Monotonic Stack**: Next greater/smaller element, histogram problems
- **Monotonic Deque**: Sliding window maximum/minimum
- Key: Remove elements that can never be the answer

#### 3. **Union Find (DSU) with Path Compression**
- Time complexity: O(α(n)) ≈ O(1) per operation
- Essential for: Connected components, cycle detection, dynamic connectivity
- Lee215's strength: 25+ problems solved with elegant DSU

#### 4. **Bit Manipulation Tricks**
- `n & (n-1)`: Remove rightmost 1 bit
- `n & -n`: Get rightmost 1 bit
- `x ^ y`: Find different bits
- Gray Code: `i ^ (i >> 1)`

#### 5. **DP Optimization**
- **Monotonic Queue + DP**: Optimize O(nk) to O(n) (e.g., Jump Game VI)
- **State Compression**: Use bitmask for DP states
- **Space Optimization**: Rolling array technique
