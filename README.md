## Learning Roadmap

### Phase 1: Foundations (Weeks 1-2)
**Goal:** Master basic data structures and simple algorithms

1. **Arrays & Hash Tables**
   - Two Sum, Contains Duplicate
   - Best Time to Buy and Sell Stock
   - Product of Array Except Self

2. **Strings**
   - Valid Parentheses
   - Longest Substring Without Repeating Characters

3. **Linked Lists**
   - Reverse Linked List
   - Merge Two Sorted Lists
   - Detect Cycle

### Phase 2: Intermediate Patterns (Weeks 3-4)
**Goal:** Learn common algorithmic patterns

1. **Binary Search**
   - Binary Search
   - Search in Rotated Sorted Array
   - Find Peak Element

2. **Trees**
   - Maximum Depth of Binary Tree
   - Invert Binary Tree
   - Validate Binary Search Tree

3. **Stacks & Backtracking**
   - Remove K Digits
   - Subsets

### Phase 3: Advanced Topics (Weeks 5-6)
**Goal:** Tackle complex problems and optimize solutions

1. **Dynamic Programming**
   - Climbing Stairs
   - House Robber
   - Coin Change
   - Longest Increasing Subsequence

2. **Graphs**
   - Number of Islands
   - Course Schedule
   - Clone Graph

3. **Heaps**
   - Kth Largest Element
   - Top K Frequent Elements
   - Find Median from Data Stream

### Phase 4: Advanced Problem Solving (Weeks 7-8)
**Goal:** Master hard problems and optimize solutions

1. **Advanced DP**
   - Longest Common Subsequence
   - Edit Distance
   - 0/1 Knapsack

2. **Hard Problems**
   - Trapping Rain Water
   - Median of Two Sorted Arrays
   - Serialize and Deserialize Binary Tree

## How to Use This Repository

### 1. **Study by Topic**
Navigate to specific category folders to focus on one data structure at a time.

### 2. **Follow the Roadmap**
Use the learning roadmap above to build knowledge progressively from fundamentals to advanced topics.

### 3. **Practice Patterns**
Many problems use similar patterns:
- **Two Pointers**: Arrays, Linked Lists
- **Sliding Window**: Strings, Subarrays
- **Fast & Slow Pointers**: Linked Lists, Cycles
- **DFS/BFS**: Trees, Graphs
- **Dynamic Programming**: Optimization problems
- **Monotonic Stack**: Next greater/smaller element

### 4. **Compare Solutions**
Most problems include multiple approaches:
- Brute force vs optimized
- Iterative vs recursive
- Different data structures

### 5. **Build Projects**
After mastering fundamentals, build:
- LRU Cache implementation
- Graph algorithm library
- Custom data structures

## Coding Patterns Reference

### Common Patterns

1. **Sliding Window** - Substring problems, max/min subarrays
2. **Two Pointers** - Sorted arrays, palindromes
3. **Fast & Slow Pointers** - Cycle detection, middle of list
4. **Merge Intervals** - Overlapping intervals
5. **Cyclic Sort** - Missing numbers in range
6. **In-place Reversal** - Reverse linked list
7. **Tree BFS/DFS** - Level-order, path problems
8. **Two Heaps** - Median finding
9. **Subsets** - Backtracking combinations
10. **Modified Binary Search** - Rotated arrays
11. **Top K Elements** - Heap problems
12. **K-way Merge** - Merge sorted lists
13. **Dynamic Programming** - Optimization, counting
14. **Topological Sort** - Graph dependencies
